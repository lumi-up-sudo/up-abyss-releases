# up어비스

어비스·시공·보스 일정, 랭킹 포인트 변화, 신석과 회복 감소 알림을 표시하는 Windows 오버레이입니다.

## 처음 설치

1. [최신 버전 다운로드](https://github.com/lumi-up-sudo/up-abyss-releases/releases/latest)를 엽니다.
2. 첨부 파일 중 **up-abyss-버전.zip**을 받습니다.
3. 압축을 **모두 풀고**, 폴더 안의 **up어비스.exe**를 실행합니다. 함께 들어 있는 runtime·receiver 폴더도 필요합니다.
4. 설정에서 서버와 현재 A/B/C 그룹을 선택합니다.

GitHub 가입이나 로그인, 초대 코드는 필요하지 않습니다.

## 다음 업데이트

- 일반 설정에서 **새 버전 자동 다운로드 · 다음 실행 때 적용**을 켜 두면 새 버전을 받아 둡니다.
- 앱을 완전히 종료하고 다시 실행할 때 적용합니다. **×는 트레이 숨기기**이므로, 완전히 종료하려면 트레이 메뉴의 종료를 사용하세요.
- 게임 중에는 업데이트 때문에 앱을 강제로 재시작하지 않습니다.
- 개인 설정을 유지하며, 네트워크 문제로 업데이트를 받지 못해도 현재 버전을 계속 사용할 수 있습니다.
- **테스트 버전도 받기**는 원하는 사람만 선택하면 됩니다.

자동 업데이트 기능이 없는 이전 버전을 쓰고 있다면, 이번 버전은 한 번 직접 내려받아 실행하세요.

`up-abyss-update.zip`과 `release.json`은 앱의 자동 업데이트용 파일입니다. 처음 설치할 때는 `up-abyss-버전.zip`을 선택하세요.

이 저장소는 공개 배포 파일과 업데이트 목록을 제공합니다. 개인 설정·진단 기록·배포용 비밀 키는 포함하지 않습니다.
